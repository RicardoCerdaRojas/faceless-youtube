Política de privacidad

Vigente desde el 5 de noviembre de 2026

Publicador YouTube Ricardo (en adelante, "la aplicación") es una herramienta de uso personal de Ricardo Cerda. Sirve para subir y programar videos en los canales de YouTube que él administra. No es un servicio abierto al público.

Qué datos usa

Cuando el titular de un canal autoriza la aplicación con su cuenta de Google, esta obtiene acceso, mediante las YouTube API Services, a:

  • la identificación del canal autorizado (ID y nombre), para confirmar que se publica en el canal correcto;
  • la capacidad de subir videos, definir sus miniaturas, títulos, descripciones, etiquetas y fecha de publicación, y agregarlos a listas de reproducción;
  • la capacidad de actualizar la descripción, las palabras clave y el banner del canal.

La aplicación no lee comentarios, mensajes, estadísticas, datos de suscriptores ni ninguna otra información de los usuarios de YouTube.

Dónde se guardan

La autorización (token de OAuth) se guarda solo en el computador de quien ejecuta la aplicación, en un archivo local con permisos restringidos. La aplicación no tiene servidores, no guarda datos en la nube y no envía información a terceros. Solo se comunica con las APIs de Google.

Después de cada subida, la aplicación registra localmente el ID del video, el ID del canal y la fecha programada, para no subir dos veces el mismo video.

Con quién se comparten

Con nadie. Los datos no se venden, no se transfieren y no se usan para publicidad, perfiles ni ningún fin distinto de publicar los videos del propio canal.

El uso de la información recibida de las APIs de Google se ajusta a la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

YouTube y Google

La aplicación usa las YouTube API Services. Al usarla, aceptas las Condiciones del Servicio de YouTube. El tratamiento de datos por parte de Google se rige por la Política de Privacidad de Google.

Cómo revocar el acceso

Puedes retirar el acceso en cualquier momento desde la configuración de seguridad de tu cuenta de Google (Terceros con acceso a tu cuenta). También puedes borrar el archivo local de autorización. Al revocar el acceso, la aplicación deja de poder usar la cuenta de inmediato.
